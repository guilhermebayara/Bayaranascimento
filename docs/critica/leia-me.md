# Críticas de design

Os relatórios das críticas de design (o padrão está em `claude/critica-design.md`, no Projeto "Gestão de projetos"). Cada um nasceu numa branch própria, sem PR, e foi copiado para cá quando virou insumo de brief, para continuar existindo depois que a branch for apagada.

- `2026-11-22-fluxos-do-natal.md`: crítica C1 (branch `critica-2026-11-22`).
- `2026-11-22-fluxos-do-natal-2.md`: crítica C2 (branch `critica-2-2026-11-22`).
- `esbocos/`: os esboços da C2, que na branch ficavam em `public/esbocos-critica/`. Aqui eles não são publicados; para ver, abra o arquivo no navegador, na mesma pasta do `base.css`.

Os links "Onde ver" dos relatórios apontam para as prévias das branches de crítica e deixam de abrir quando elas forem apagadas. As respostas do Gui estão em `docs/decisoes.md`, "Decidido, a construir", e os briefs que saíram delas em `docs/briefs/`.
