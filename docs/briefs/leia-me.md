# Briefs

Um arquivo por item grande de "Decidido, a construir" (`docs/decisoes.md`): o que o Gui decidiu, o porquê, o que já está combinado e o que a sessão ainda precisa decidir ou perguntar. A lista guarda só uma linha com o link. Quando o item é construído, o brief vai para `docs/historico/briefs/` e as regras entram no arquivo do assunto, em `docs/regras/`.
